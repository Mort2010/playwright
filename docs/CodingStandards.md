# Coding Standards

## Filenames
For classes Pascal is in use so the filenames will have a capital at start of each word. Not required but flows with the standard of classes.

## Folder Names
All lower folder names have been kept lower case just for ease of use. The - is in auto created folders the _ in manual ones something to address later if time allows to make a better standard or possibly leave to enable easy determination of auto folders and manual ones.4
